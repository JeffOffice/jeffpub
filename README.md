# JeffPub is now part of JeffOffice

JeffPub, the desktop publishing app, is now one of the apps in **JeffOffice**, a free, open-source office suite from JeffOffice LLC.

- Code, releases, and help: **https://github.com/JeffOffice/jeffoffice**
- Latest downloads: **https://github.com/JeffOffice/jeffoffice/releases/latest**

This repository only holds the newest installer, so copies of JeffPub from before version 0.6.11 can still find the update.
