# Contents, footnotes, and endnotes
<!-- keywords: table of contents, toc, contents page, footnote, endnote, notes, references, citations, update table, page numbers, dot leader, heading styles -->

The **References** group on the **Insert** tab has tools for long publications: a table of contents, footnotes, and endnotes.

## Add a table of contents

A table of contents lists your headings with their page numbers, so readers can find things.

1. Give each heading one of the styles **Heading 1**, **Heading 2**, or **Heading 3**. See [Use styles](styles).
2. Click in the text where you want the table, or click an empty page.
3. Click **Insert > References > Table of Contents**.

JeffPub adds a title, **Contents**, and one line for each heading. Each line ends with a row of dots and a page number. **Heading 1** lines are bold, and the lower levels are indented a quarter inch each.

If you clicked in text, the table goes right there. If not, and the page is empty, it goes in a new text box on that page. Otherwise JeffPub adds a new page after this one for it.

If there are no headings yet, the table says so. Add headings, then update it.

### Keep it up to date

The table does not change by itself. After you edit headings or move pages around, click **Insert > References > Update Table**. All page numbers refresh, and every table in the publication updates. JeffPub writes the whole table again, so do not type changes inside it. Change the headings instead.

## Add a footnote

A footnote is a short note at the bottom of the page. A small raised number in the text points to it.

1. Click in the text where the number should go.
2. Click **Insert > References > Footnote**, or press Ctrl+Alt+F.
3. Type the note in the **Insert Footnote** dialog.
4. Click **OK**.

JeffPub numbers footnotes 1, 2, 3, and so on. It places each note at the bottom of the column that holds its number, under a short line. The note text is a little smaller than your text. A note that is taller than a whole column is not split.

## Add an endnote

An endnote is like a footnote, but all the notes are collected together at the end of the story, under the heading **Notes**.

1. Click in the text where the number should go.
2. Click **Insert > References > Endnote**, or press Ctrl+Alt+D.
3. Type the note in the **Insert Endnote** dialog and click **OK**.

## Change a note

Click right next to a note's number in the text, and click **Footnote** or **Endnote** again. The **Edit Footnote** or **Edit Endnote** dialog opens with the note's words. To remove a note, delete its number in the text.

Notes work in text boxes. They do not work in table cells.
