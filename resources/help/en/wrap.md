# Wrap text around objects
<!-- keywords: text wrap, wrap text, square, tight, through, top and bottom, in line with text, inline, wrap points, text around picture, text flows around, wrap distance, runaround -->

Text wrapping decides how the words in a text box flow around a picture or shape that overlaps it. Without wrapping, the words would run behind the picture. With wrapping, the words go around it.

Text wraps only around objects that are in front of the text box. If a picture is behind the text box, select the picture and choose **Bring to Front**. See [Move, align, group, and layer objects](arrange).

## Choose a wrap

1. Select the picture or shape.
2. Click **Home > Arrange > Wrap Text**. The same button is on the **Shape Format** and **Picture Format** tabs. You can also right-click the object and choose **Wrap Text**.
3. Choose a style:

- **None**: text ignores the object.
- **Square**: text stays outside a rectangle around the object, even if the object is round.
- **Tight** and **Through**: text follows the outline of the object.
- **Top and Bottom**: text stops above the object and starts again below it. Nothing sits beside the object.
- **In Line with Text**: the object becomes part of the text, like a very large letter. It sits on a line and moves with the words.

New pictures, shapes, and text boxes start with **Square**. Lines start with **None**.

If an object covers a whole text box, the text does not move aside for it.

## Put an object in line with text

1. Drag the object over a text box. The object goes into the text where its top left corner sits.
2. Select the object and choose **Wrap Text > In Line with Text**.

If you see a hint about moving the object over a text box first, do step 1 and try again. To take the object back out, click in the text beside it, press **Shift** and an arrow key to select it, and choose any other wrap.

## Set the side and the space

Click **Wrap Text > More Layout Options…**. The **Layout** tab has these settings:

- **Wrapping style**: the same styles as the menu, except **In Line with Text**.
- **Wrap text**: **Both sides**, **Left only**, **Right only**, or **Largest side**.
- **Distance from text**: the space between the object and the text on the top, bottom, left, and right. The standard space is 0.04 inch.

## Edit the wrap points

Wrap points are the dots that mark the edge text avoids. Moving them lets text follow an odd shape.

1. Select the picture or shape.
2. Click **Wrap Text > Edit Wrap Points**. If the wrap is not **Tight** or **Through**, it switches to **Tight**.
3. Drag a point to move it. Drag an edge to add a point. **Ctrl**+click a point to delete it. At least three points stay.
4. Press **Esc** when you are done.
