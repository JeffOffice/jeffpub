# Text Box tab
<!-- keywords: text box tab, text box tools, contextual tab, text fit, link text boxes, drop cap, text effects, typography, columns, margins -->

The **Text Box** tab appears, under the label **Text Box Tools**, when you select a text box or click in one. It goes away when you select something else.

- **Text** has **Text Fit**, **Text Direction**, and **Hyphenation**. See [Add and format text boxes](text-boxes).
- **Alignment** places text left, center, right, justified, or distributed, and at the top, middle, or bottom of the box. It also has **Columns** and **Margins**. See [Add and format text boxes](text-boxes).
- **Linking** has **Create Link**, **Break**, **Previous**, and **Next** for flowing a story through several boxes. See [Flow text between text boxes](linked-text).
- **Font** repeats the font, size, and style tools from the **Home** tab. See [Format text](formatting-text).
- **Effects** has **Shadow**, **Outline**, **Emboss**, **Engrave**, **Text Fill**, **Text Outline**, and **Text Glow** for the letters themselves. See [Format text](formatting-text).
- **Typography** has **Drop Cap** and finer font features such as **Number Style**, **Ligatures**, **Stylistic Sets**, **Swash**, **Stylistic Alternates**, and **True Small Caps**. See [Format text](formatting-text).
- **Arrange** controls text wrap, stacking order, grouping, alignment, and rotation of the box. See [Move, align, group, and layer objects](arrange).
- **Size** sets the height and width of the box. See [Move, align, group, and layer objects](arrange).
