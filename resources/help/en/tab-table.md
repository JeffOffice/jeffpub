# Table Design and Table Layout tabs
<!-- keywords: table design, table layout, table tools, contextual tab, borders, cell fill, merge cells, insert row, delete column, table formats, gridlines -->

The **Table Design** and **Table Layout** tabs appear, under the label **Table Tools**, when you select a table or click in a cell. Design is for the look of the table. Layout is for its structure.

## Table Design

- **Table Formats** is a gallery of ready-made looks. See [Make and edit tables](tables).
- **Fill** has **Cell Fill**, which colors a cell or the whole table. See [Make and edit tables](tables).
- **Borders** has **Line Color**, **Line Weight**, and a **Borders** menu that draws lines on chosen sides. See [Make and edit tables](tables).
- **Alignment** holds **Diagonals**, which draws a line from corner to corner of a cell. See [Make and edit tables](tables).

## Table Layout

- **Table** has **Select**, for the cell or the whole table, and **View Gridlines**. See [Make and edit tables](tables).
- **Rows & Columns** inserts rows and columns above, below, left, or right, and deletes rows, columns, or the table. See [Make and edit tables](tables).
- **Merge** has **Merge Cells** and **Split Cells**. See [Make and edit tables](tables).
- **Alignment** puts text at the top, middle, or bottom of a cell, and left, center, right, or justified. See [Make and edit tables](tables).
- **Size** has **Grow to Fit Text**, **Distribute Rows**, and **Distribute Columns**. See [Make and edit tables](tables).
- **Arrange** controls text wrap, stacking order, grouping, alignment, and rotation. See [Move, align, group, and layer objects](arrange).
