# Use styles
<!-- keywords: style, styles gallery, paragraph style, character style, heading 1, heading 2, heading 3, title, new style, modify style, change style, import styles, normal, body text, subtitle -->

A style is a saved set of formatting with a name. When you apply the style **Heading 1**, the text gets that style's font, size, color, and spacing all at once. Change the style later, and every paragraph that uses it changes too.

There are two kinds of style:

- A **paragraph style** formats whole paragraphs.
- A **character style** formats only the letters you select. **Emphasis** (italic) and **Strong** (bold) are character styles.

## Apply a style

1. Click in a paragraph, or select the text. For a character style, select the words.
2. In **Home > Styles**, click a style in the gallery.

With a text box selected instead, the style applies to all its paragraphs. The gallery shows a few styles. Use the **Previous row** and **Next row** arrows to see more, or the **Show all** button to see them all.

A new publication starts with these styles: Normal, Body Text, Title, Subtitle, Heading 1 to Heading 4, Quote, Caption, List Bullet, Address, Organization Name, Tagline, Phone Fax Email, Emphasis, and Strong. The heading styles use the publication's heading font, so choosing a new font scheme changes them. See [Color and font schemes](color-schemes).

Use **Heading 1**, **Heading 2**, and **Heading 3** for your headings. JeffPub builds a table of contents from them. See [Contents, footnotes, and endnotes](references).

## Make a new style

1. Format some text the way you want the style to look. Leave the caret in it.
2. Click **Show all** in the **Styles** gallery, and then click **New Style…**.
3. Type a **Style name**. Check or change the other settings.
4. Click **OK**.

The new style appears in the gallery. It is not applied to your text yet, so click it there.

For a faster way, choose **New Style by Example**. Type a name for the style, based on the selected text. JeffPub makes the style and applies it at once.

## Change a style

1. Click in a paragraph that uses the style.
2. Click **Show all** in the **Styles** gallery, and then click **Modify Style…**.
3. Change the font, size, bold, italic, color, alignment, or spacing. Click **OK**.

Every paragraph with that style changes right away.

The dialog also has these choices:

- **Style for the next paragraph:** the style you get when you press Enter at the end of a paragraph. After a heading, you usually want **Normal**.
- **Character style:** check it to make a style that formats only selected text.
- **Based on:** JeffPub saves this choice, but a style does not change when the style it is based on changes.

## Bring in styles from another publication

1. Click **Show all** in the **Styles** gallery, and then click **Import Styles…**.
2. Choose a JeffPub publication or a .pub file.

Styles with the same name are replaced. Other styles are added. Text you have already written keeps its look until you apply the style again.
