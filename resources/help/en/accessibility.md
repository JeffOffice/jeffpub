# Screen readers, high contrast, and alt text
<!-- keywords: accessibility, screen reader, narrator, blind, low vision, high contrast, dark mode, dark theme, focus outline, alt text, alternative text, picture description, zoom, magnify, keyboard only -->

JeffPub is built so that people who use screen readers, the keyboard, or high-contrast colors can use it too.

## Screen readers

A **screen reader** is a program that reads the screen aloud. JeffPub works with screen readers such as Narrator on Windows. Every control has a name and a description. This includes the ribbon's tabs, buttons, galleries, and color buttons, the Pages list, the page, the task panes, and the status bar.

The objects on the page are read too. On the page, press **Tab** to select the next object: the screen reader says what kind it is and what it holds, such as "Text box: Spring sale" or "Picture: a red barn", then where it is and how big. A picture without alt text is read as "Picture, no alt text", so you know which ones still need it. Press **Enter** to type in a text box; the screen reader can then read its text, the line or word the cursor is on, and what you select.

- The Pages list reads each page as "Page 1", "Page 2", and so on. If you gave a page a name, the name follows, as in "Page 3, Cover".
- The page area is called "Page". Its description tells you the keys to use: Tab selects the next object, the arrow keys move it, Enter edits its text, and Delete removes it.
- Tabs are read as ribbon tabs. Tabs that appear when you select something also name their group, such as Picture Tools.

## Use the keyboard

You can reach the ribbon, the Pages list, and the objects on the page with the keyboard alone. Press F6 to move between the ribbon, the Pages list, and the page. Press Alt to see KeyTips. A colored outline shows which control has the focus. See [Use JeffPub with the keyboard](keyboard).

## Change the colors

- **Dark or light**: click **File > Options**, and on the **General** tab, set **Theme** to **Light**, **Dark**, or **Use system setting**. The change happens at once.
- **High contrast**: on Windows, when you turn on a high-contrast theme, JeffPub follows it. It uses the colors Windows chose, and it changes as you turn the theme on or off.

## Make pictures easier to understand

**Alt text** (alternative text) is a short description of a picture or other object. Screen readers read it aloud. JeffPub also puts it in web pages and e-books you save.

1. Right-click the picture or object.
2. Click **Format Object…**.
3. Click the **Alt Text** tab.
4. Type a description in the **Alternative text** box.
5. Click **OK**.

Say what the picture shows, in a few words, such as "Two children planting a tree". Icons and barcodes you insert get alt text by themselves.

## Make the page bigger

Zoom in to read small text. Use the **Zoom** controls in the status bar, hold Ctrl and turn the mouse wheel, or pick a size in the **Zoom** box on the **View** tab. The zoom slider goes from about 10% to 1600%.
