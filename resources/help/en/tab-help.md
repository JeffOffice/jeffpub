# Help tab
<!-- keywords: help tab, help, support, contact support, feedback, whats new, release notes, keyboard shortcuts, F1, report a problem, suggest an idea -->

The **Help** tab is always on the ribbon, after the **View** tab. Use it to get help, report a problem, or suggest an idea.

- **Help** group: five buttons. See [Welcome to JeffPub](start) and [Get help and report problems](support).

| Button | What it does | KeyTip |
|---|---|---|
| **Help** | Opens the Help pane on the right. You can also press F1 or click the **?** button at the right end of the tab row. | Alt, Y, H |
| **Contact Support** | Opens a GitHub page where you report a problem. You need a free GitHub account. | Alt, Y, C |
| **Feedback** | Opens a GitHub page where you suggest an idea. You need a free GitHub account. | Alt, Y, K |
| **Keyboard Shortcuts** | Opens the help topic about using JeffPub with the keyboard, with a list of every command's keys. | Alt, Y, S |
| **What's New** | Opens the notes for your version of JeffPub on GitHub, in your web browser. | Alt, Y, W |
