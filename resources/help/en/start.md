# Welcome to JeffPub
<!-- keywords: welcome, getting started, introduction, beginner, first steps, quick start, overview, what is JeffPub, basics, tutorial, how to use help, new user, learn -->

JeffPub is a program for laying out pages. Use it to make flyers, newsletters, brochures, greeting cards, business cards, calendars, booklets, and e-books. It is free and open source. There is no fee, no subscription, and no account to set up.

The file you work on is called a **publication**. It can have one page or many. JeffPub saves its own publications as .jpub files. It also opens and saves .pub files, so you can keep working on older publications.

## Do these four things first

1. **Start a publication.** When JeffPub starts, it shows the **New** page. Pick a ready-made design (called a template) or a blank page. Then click **Create**. See [Start a new publication](create).
2. **Add your words and pictures.** Click a text box on the page to select it, then type. To add a picture, click **Insert > Illustrations > Pictures**. See [text boxes](text-boxes) and [pictures](pictures).
3. **Save your work.** Press Ctrl+S. The first time, JeffPub asks for a name and a place. See [Open and save publications](open-save).
4. **Print or share.** Press Ctrl+P to print. To make a PDF, click **File > Export**, then **Create PDF**. See [Print a publication](printing) and [PDF files and print shops](pdf).

## Find your way around

The ribbon across the top holds the buttons. The Pages list on the left shows a small picture of each page. The page itself is in the middle. See [Find your way around the window](window).

## Get help while you work

- Press **F1**. The Help pane opens on the right. It shows help about what you are doing: the ribbon tab you are on, the dialog you have open, or the object you selected. Over a dialog or the File page, Help opens in a small window of its own.
- You can also click the **?** button at the right end of the tab row, or click **Help > Help > Help**.
- Type a word in the search box at the top of the pane. It finds help topics and also commands. If you choose a command, JeffPub runs it.
- Click a link to jump to another topic. Click **Back** to return to the topic you read before, and **Forward** to go the other way. Click **Contents** (the little house) to see the list of all topics.
- Click **Help > Help > Keyboard Shortcuts** to see the keys you can press. Or read [Use JeffPub with the keyboard](keyboard).

If something goes wrong, see [Get help and report problems](support).
